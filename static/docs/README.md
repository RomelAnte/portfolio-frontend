## Regla de versionado

- Esta carpeta si permanece en Git porque contiene archivos reales ademas de este `README.md`.
- No crees subcarpetas aqui solo para guardar otro `README.md`.
- Si agregas nuevos documentos, usa nombres descriptivos y evita duplicados temporales.

## Recomendaciones

- Mantener nombres estables para no romper enlaces existentes.
- Si un documento es privado o muy pesado, no lo subas al repo: usa almacenamiento externo o ajusta `.gitignore`.
